АРМ стоматологической клиники «Ассоль»
(модуль администратора + модуль главного врача)

Запуск:
1. Установить Python 3.10+.
2. Открыть командную строку в папке проекта.
3. Выполнить: pip install -r requirements.txt
4. Выполнить: python app.py
   либо запустить run.bat.

Демонстрационный вход:
  Администратор:  логин admin,  пароль admin
  Главный врач:   логин chief,  пароль chief

Главному врачу доступны только разделы администрирования:
  «Врачи» (добавление, изменение, удаление),
  «График работы» (рабочие дни и часы приёма врачей),
  «Учётные записи» (учётные записи администраторов).

Тесты:
  python -m unittest -v test_app test_chief

Данные хранятся в SQLite-файле assol_clinic.db (создаётся при первом запуске;
база предыдущей версии АРМ обновляется автоматически).
